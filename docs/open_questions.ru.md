# Открытые вопросы

*Перевод с английского выполнен с помощью ИИ (Claude). При расхождениях верна [английская версия](open_questions.md).*

## Группы с точками
`r.s.f.d. c.f. f.t′.f.` (S1), `r.l.b. s.n.c.` (S2), `r.l.n.` (S3), `d.s.z.` (S4), `n.t.d.` (S5), `n′.r.n.` (S6).

- Это буквы песни: квадраты совпадают с песней только тогда, когда их буквы учитываются.
- Они подобраны: 27 букв, все согласные, всего десять разных (b c d f l n r s t z), тогда как среди 27 случайных букв песни было бы около десяти гласных.
- Они расставлены: в средней строке или парами, симметричными относительно центра.
- В S2 вторая группа это первая, сдвинутая на одну букву в алфавитном ряду b c d f l n r s t z (r→s, l→n, b→c). Это похоже на код из десяти букв для цифр в алфавитном порядке.
- При таком коде ни одна группа не читается как очевидная дата, а четырёхбуквенная группа S1 не может означать 19xx.

Скорее всего, это числа (дата, класс, номер школы), записанные кодом из десяти согласных. Один внешний факт, например год закладки, класс или школа, позволил бы восстановить код.

## Оставшиеся расхождения
Песня, разрезанная один раз на шесть кусков, объясняет S2 с точностью до одной буквы. В S1 и S3 клеток меньше, чем букв в их кусках (166 и 162 вместо примерно 169: автор пропустил несколько букв); S4, S5 и S6 расходятся с текстом на 8–12 лишних или недостающих букв (`results/partition.txt`). Для S4 расхождения есть на самой бумаге: на сканах 2015 года лишние *l* написаны чётко. Остальные квадраты буква за буквой не перепроверялись; вторая страница (конец S5 и весь S6) повреждена водой, и несколько её букв остаются сомнительными. Описки ли это автора или другая редакция печатного текста, с которого переписывал автор, неизвестно; это решил бы песенник ГДР или школьное издание песни.
