## The dotted groups
`r.s.f.d. c.f. f.t′.f.` (S1), `r.l.b. s.n.c.` (S2), `r.l.n.` (S3), `d.s.z.` (S4), `n.t.d.` (S5), `n′.r.n.` (S6).

- They are letters of the song: the squares only match the song when they are counted in.
- They are chosen: 27 letters, all consonants, only ten different ones (b c d f l n r s t z), while 27 letters taken at random from the song would include about ten vowels.
- They are placed: middle row or centre-symmetric pairs.
- In S2 the second group is the first group shifted by one letter in the alphabetical list b c d f l n r s t z (r→s, l→n, b→c), which suggests a 10-letter digit code in alphabetical order.
- Under such a code no group reads as an obvious date, and S1's four-letter group cannot read 19xx.

Most likely: numbers (a date, a class, a school number) in a 10-consonant code. One outside fact, such as the year of burial, the class or the school, would fix the code.

Whether the differences are the writer's slips or the wording of the printed copy the writer used is open; a GDR songbook or school printing of the song would settle it.
