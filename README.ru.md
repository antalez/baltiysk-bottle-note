# Записка из бутылки в Балтийске: расшифрована

*Перевод с английского выполнен с помощью ИИ (Claude). При расхождениях верна [английская версия](README.md).*

В 2015 году рабочие копали траншею под газопровод у дома 64–66 по улице Ленина в Балтийске (Калининградская область, бывший Пиллау) и нашли бутылку. Внутри были два тетрадных листа, исписанные группами букв, которые никто не смог прочесть: *"en'ifvn d't'öhn'fdê elhrikiracel etê deluwrs …"*. Записка заняла 19-е место в списке важнейших нерасшифрованных сообщений Клауса Шмеха.

**Это песня.** В записке записан текст песни ГДР **«Einheitslied»** («Песня единства») из *Freundschaftskantate der Jugend* («Кантата дружбы молодёжи»; слова Херберта Келлера, музыка Андре Асриэля). Её куплеты *Freundschaft! Allen Völkern Freundschaft …*, *Einheit! …* и начало куплета *Frieden! …* разрезаны на шесть идущих подряд кусков примерно по 169 букв. Каждый кусок вписан в квадрат 13 × 13, буквы внутри квадрата перемешаны, затем квадраты переписаны по строкам с придуманными пробелами между «словами». Под последним квадратом стоит **«eimat»** и точки. Скорее всего, это конец слова *Heimat* («Родина»; в песне *«Singen soll die Heimat»*), которое идёт в тексте через несколько слов после последнего квадрата.

## Доказательство

Перемешивание букв внутри квадрата меняет их порядок, но не количество. Разрежем песню **один раз** на шесть кусков подряд, без перекрытий и пропусков (`src/partition.py`), и вычеркнем в каждом квадрате буквы, которые использует его кусок:

| Квадрат | Клеток | Кусок песни (номера букв) | Лишнее в квадрате | Не хватает букв текста |
|---|---|---|---|---|
| S1 | 166 | 0–157: *"Freundschaft! Allen Völkern Freundschaft …"* | d e e e i l l n s s t | f u |
| **S2** | **169** | **157–325**: *"…werden wir erringen, wenn wir fest zusammenstehn …"* | **l** | **нет** |
| S3 | 162 | 325–495: *"…unser Deutschland ganz gehören … Einheit! …"* | e e | c c i i l n n r r u |
| S4 | 169 | 495–658: *"…wollen alle guten Menschen für das deutsche Land …"* | i i l l l l n n t | e e e |
| S5 | 169 | 658–827: *"…keine Bombe zerstören … Frieden!"* | d f n n | h i s u |
| S6 | 143 | 827–974: *"…Völkern Frieden … wenn wir fest zusammensteh(n)"* | a d s s | c m r r t u u u |

S2 по буквам: все 168 букв его куска есть в квадрате, одна *l* лишняя.

```
буква    e   n   s   r   i   f   h   u   w   l   d   a   o   t   m   c   g   b   k   z   p
квадрат 28  24  16  14  13   7   7   7   7   7   6   6   5   5   4   3   3   2   2   2   1
песня   28  24  16  14  13   7   7   7   7   6   6   6   5   5   4   3   3   2   2   2   1
```

Что остаётся в других квадратах. В S1 и S3 клеток меньше, чем букв в их кусках (166 и 162 вместо 169): автор пропустил несколько букв. Остальные квадраты расходятся с текстом на несколько букв. Для S4 мы проверили по сканам 2015 года: лишние *l* написаны чётко, это именно *l*. Значит, расхождения есть на самой бумаге (описки автора или другая редакция текста, с которой переписывал автор). Остальные квадраты буква за буквой не перепроверялись.

## Почему это не совпадение

Все числа ниже считаются одной мерой: лишние буквы в квадрате плюс буквы текста, которых в квадрате нет.

- **Случайность.** В 8,9 млн букв немецких новостей (корпус Лейпцигского университета) лучший отрезок для каждого квадрата, выбранный свободно, оставляет 20–36 несовпадающих букв (для S2 24). Песня, разрезанная один раз на куски подряд, оставляет для S2 одну букву, для остальных 8–13 (`src/null_test.py`, `results/null_test.txt`).
- **Другие расшифровки.** Транскрипция с сайта d3.ru (июль 2015) и транскрипция Томаса Эрнста (2017) дают для S2 тот же результат, что и наша: все 168 букв и одна лишняя *l*. Наша транскрипция начиналась с транскрипции Эрнста и была заново проверена знак за знаком (`src/check_transcriptions.py`, `results/check_transcriptions.txt`).
- **Порядок.** Лучший отрезок песни для каждого квадрата, найденный независимо, идёт в том же порядке, что и в песне (вероятность случайно 1 из 720; `src/significance.py`).
- **Пометки.** Апострофы отмечают концы слов. В S1, S3 и S4 никакой другой отрезок песни не совпадает с помеченными буквами квадрата так хорошо, как его собственный кусок (p ≈ 0,001 для каждого); для S2 p ≈ 0,01, для S5 ≈ 0,07, для S6 незначимо (`results/significance.txt`).

## Как была сделана записка

- **Куски.** Буквы песни (без пробелов и знаков препинания; *ö* и *ü* автор сохранил) разрезаны на куски подряд примерно по 169 = 13 × 13 букв. Начинается ли S1 с названия *Einheitslied*, не установлено: с названием общее совпадение немного лучше (`results/partition_with_title.txt`).
- **Заполнение.** Каждый кусок вписан в свой квадрат буква за буквой, с движением вправо и вниз: следующая буква песни чаще случайного стоит на 2–4 клетки правее в той же строке или в следующей строке и почти никогда не возвращается в строку выше. Это видно в каждом квадрате и ясно видно в сумме (`results/structure.txt`). Точный порядок записи восстановить нельзя: в песне слишком много повторяющихся букв.
- **Концы слов помечены.** Апостроф ставится на последнюю букву слова (*t′* в конце *Freundschaft*, *Einheit*, *Welt*; *n′* в конце *allen*, *wollen*, *singen* …); *ê* означает *e* в конце слова (`results/marks.txt`).
- **Переписано** по строкам на два листа с придуманными пробелами; последняя буква каждого квадрата подчёркнута.
- **Группы с точками** (*r.s.f.d. c.f. f.t′.f.*, *r.l.b. s.n.c.*, …): буквы песни в заранее оставленных клетках вокруг центра квадрата. Их смысл не установлен (см. `docs/open_questions.ru.md`).

## Как её нашли

Записка сама указала путь. Её разделы оказались квадратами 13 × 13, заполненными вручную: соседние буквы между собой не связаны, и никакой ключ или правило не возвращает их в порядок (сотни решёток, маршрутов и перестановок по ключу не сработали; см. `docs/method.ru.md`). Значит, текст можно было только **узнать**, а не расшифровать. Разделы 2–5 делят между собой примерно по 60 одинаковых букв, которых нет в разделе 1: так выглядят куплеты с припевом после вступления. Буквы к тому же указывают на немецкую речь от лица «мы» («wir werden … wenn …», «мы будем … если …») со словами вроде *Freundschaft* (дружба), *Frieden* (мир) и *Heimat* (родина), а под последним квадратом стоит *eimat*. Это указывало на песню пионерского или молодёжного типа. Количество букв не меняется при любом перемешивании, поэтому каждый квадрат сравнивался по количеству букв со всеми отрезками текстов-кандидатов. Библия, немецкий Викитекст, книги, советско-немецкая газета *Freundschaft*, немецкие народные песни и русские песни совпадений не дали. Песня «Einheitslied» нашлась в собрании из 1 762 песен и стихов, большая часть которого взята из архива песен ГДР *lieder-aus-der-ddr.de*.

## Как проверить

```bash
pip install numpy
python src/fetch_song.py           # скачивает текст песни в data/song.txt (в репозитории его нет)
cd src
python squares.py                  # шесть квадратов
python partition.py                # песня, разрезанная один раз на шесть кусков; лишнее и недостающее в каждом квадрате
python verify.py                   # лучший отрезок песни для каждого квадрата, найденный независимо
python marks.py                    # апострофы и концы слов
python significance.py             # проверка порядка и пометок
python check_transcriptions.py     # S2 по транскрипции 2015 года
python null_test.py                # проверка на случайность (скачивает ~30 МБ немецких новостей)
python sieve.py ../data/song.txt   # поиск по количеству букв (или любая папка с .txt)
python structure.py                # что видно в самой записке: строки по 13, группы с точками, припев, состав букв, ходы
```

## Интерактивная страница

Интерактивная страница показывает каждый квадрат с вычеркнутыми буквами его куска песни, лишние и недостающие буквы. Вкладка **How it was found** шаг за шагом, с графиками, показывает, какие признаки привели от записки к песне (страница на английском).

```bash
python src/fetch_song.py && python src/fetch_photos.py   # текст песни и две опубликованные фотографии записки, сохраняются локально (не распространяются)
cd src && python structure.py && python build_dashboard.py   # создаёт results/structure.json и dashboard/data.js
open ../dashboard/index.html                                # или откройте файл двойным щелчком (index.html#story открывает историю)
```
